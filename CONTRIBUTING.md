# Contribuer

1. Forkez ou creez une branche `feat/...` / `fix/...` depuis `main`.
2. Commits en conventional commits (`feat:`, `fix:`, `ci:`, `docs:`...).
3. Ouvrez une PR vers `main` — les checks CI doivent etre verts.
4. Les jobs "Quality" et certains tests d'integration sont en mode
   advisory : ils informent sans bloquer le merge.
5. Aucun secret dans le code : Gitleaks le detectera et bloquera.
